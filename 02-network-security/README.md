# Network Security

Materiais técnicos sobre Segurança de Redes e proteção
da infraestrutura corporativa.

## Conteúdos

- Firewall e Next Generation Firewall (NGFW)
- VPN e ZTNA
- SD-WAN
- Secure Web Gateway (SWG)
- DNS Security
- Network Access Control (NAC)
- Network Detection and Response (NDR)
- Proxy e inspeção de tráfego
- Segmentação de redes

## Objetivo

Compartilhar conhecimentos sobre arquitetura,
proteção e segurança de redes corporativas.
