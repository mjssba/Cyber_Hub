# Scripts and Tools

Biblioteca de scripts, automações e ferramentas
para apoiar atividades de Segurança da Informação.

## Tecnologias

- Python
- PowerShell
- Bash
- APIs
- Automação de segurança

## Projetos

- Análise de logs
- Inventário de ativos
- Verificação de conectividade
- Automação de tarefas
- Análise de indicadores de segurança
- Integração com APIs

## Objetivo

Compartilhar códigos e ferramentas desenvolvidos
para fins educacionais e profissionais.
