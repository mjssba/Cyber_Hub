# SASE & Zero Trust

Estudos e materiais sobre arquiteturas modernas
de segurança e conectividade.

## Conteúdos

- Secure Access Service Edge (SASE)
- Security Service Edge (SSE)
- Zero Trust Architecture
- Zero Trust Network Access (ZTNA)
- CASB
- SWG
- Firewall as a Service (FWaaS)
- SD-WAN
- Microsegmentação
- Identity-Based Security

## Objetivo

Compartilhar experiências, arquiteturas,
avaliações técnicas e boas práticas de SASE.
